# TOOLS

Windows 桌面工具集。当前项目：**winclean** — 磁盘空间治理工具。

## 这是什么

一个用 Go 写的 Windows 磁盘空间分析与治理工具。它不做「垃圾清理」这种收效甚微的事，而是回答三个真问题：

1. **空间被什么占了**（归因）
2. **哪些能删**（可清理性分级）
3. **哪些该搬到别的盘**（可迁移性判定）

起因很直接：本机 C 盘 237 GB 只剩 3.9 GB，而传统清理工具能安全释放的只有 2–3 GB。真正的大头是单个 36 GB 的 Docker 虚拟磁盘、24 GB 的页面文件、9.7 GB 的休眠映像，以及合计 20+ GB 的开发工具缓存——**这些一个都不该删，它们该被迁移或调整设置**。按本机数据估算，本工具的目标是回收约 100 GB。
